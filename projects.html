Selected work / Case studies

What I built, how it worked, and what I learned.

These are concise technical breakdowns, not marketing pages. They focus on the system, my contribution, and the result.

01

Published Roblox experience

Escape Tsunami with Dragons

30K+visits

Context

The experience combines a repeating tsunami survival loop with dragons, rewards, progression, and replayable systems. The goal was to make a simple idea feel active enough to keep players moving and upgrading.

What I built

  • Moving tsunami path and survival handling
  • Dragon and reward systems connected to the core loop
  • Global announcements and supporting UI
  • Server-side checks for cooldowns, range, tool state, and player state
  • Performance improvements using time-based movement and controlled update rates

Technical focus

Roblox Studio, Lua, client/server boundaries, gameplay validation, reusable systems, and performance under multiple players.

LuaRoblox StudioServer validationOptimization

What it proved

I could publish and maintain a real game rather than stop at a prototype. Reaching 30K+ visits also gave me a reason to care about performance, clarity, and systems that survive real users.

02

NLP · Retrieval

Nutrition Facts RAG Chatbot

Problem

A normal chatbot can answer confidently without grounding. This project used document retrieval so responses could be based on relevant nutrition information instead of only a model’s general memory.

Pipeline

  1. Prepare and clean nutrition documents
  2. Split content into searchable chunks
  3. Represent and rank relevant text
  4. Pass retrieved context into the answer step

Technical focus

Python, text preprocessing, sparse representations, TF-IDF, retrieval logic, prompt context, and evaluating whether answers stayed connected to the source material.

Learning

The useful part of RAG is not the label. It is the discipline of retrieving the right context and making the answer depend on it.

03

Computer vision · Classification

Emotion Detection from Facial Expressions

Goal

Classify facial-expression images into emotion categories while learning the full workflow around image preparation, model training, testing, and evaluation.

Work completed

  • Image preprocessing and dataset preparation
  • Training and test flow
  • Prediction evaluation and error inspection
  • Presentation of the project and its limitations

Technical focus

Python, image classification, preprocessing, evaluation metrics, and understanding that facial expression is not the same as a complete reading of a person’s internal emotional state.

Learning

Model output needs context and careful interpretation. A technically working classifier still has limits that should be stated honestly.

04

Low-level programming

Snake Game in Assembly

Goal

Build a complete playable game while working close to the machine: explicit input handling, state updates, screen output, collision logic, and control flow.

Systems

  • Keyboard-controlled movement
  • Food placement and score tracking
  • Body and boundary collision checks
  • Screen refresh and game-over state

Technical focus

Assembly language, registers, memory/state management, loops, branching, keyboard input, and rendering through low-level screen operations.

Learning

Low-level work makes hidden assumptions visible. Even a small game becomes a useful exercise in state, timing, and careful control flow.
