# Media replacement guide

The current site uses polished product-flow visualizations where real screenshots were not supplied. Replace them only with your own work.

## Escape Tsunami with Dragons

Recommended:

- `roblox-gameplay.webp`: 1920×1080, WebP, high-quality in-game scene with the tsunami and a dragon visible.
- `roblox-gameplay.mp4`: 1920×1080, H.264 MP4, muted, 8–15 seconds, under 12 MB. Avoid menus and loading screens.
